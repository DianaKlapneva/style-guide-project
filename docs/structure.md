# Структура документов

## Обязательные элементы

Документ должен содержать:

1. информативное название;
2. назначение;
3. область применения;
4. основную часть;
5. сведения о версии, если документ подлежит версионированию;
6. ответственное подразделение, если это требуется процессом согласования.

## Разделы и заголовки

Делите основной текст на логические разделы и подразделы. Соблюдайте последовательную иерархию заголовков.

## Последовательности действий

Последовательность действий оформляйте нумерованным списком. Один пункт должен описывать одно основное действие и ожидаемый результат, если он важен для пользователя.
