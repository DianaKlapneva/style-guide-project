# Доступность текста

Этот раздел добавляется в отдельной ветке в рамках задания по работе с Pull Request.

## Ясность текста

1. Используйте простые и однозначные формулировки.
2. Расшифровывайте специализированные сокращения при первом упоминании.
3. Не передавайте смысл только цветом, размером или расположением элемента.

## Заголовки и структура

1. Используйте последовательную иерархию заголовков без пропуска уровней.
2. Делите длинные фрагменты на короткие смысловые блоки.
3. Используйте списки только там, где элементы действительно образуют перечень или последовательность.

## Ссылки

Текст ссылки должен описывать назначение перехода. Не используйте изолированные формулировки «тут», «здесь» и «по ссылке» без контекста.

**Неправильно:** «Подробнее читайте здесь».

**Правильно:** «См. руководство по настройке системы».

## Изображения

Для содержательных изображений добавляйте альтернативное текстовое описание. Декоративные изображения не должны дублировать важную информацию.

## Таблицы

Используйте таблицы для сопоставления данных, а не для визуального расположения текста. Заголовки строк и столбцов должны быть понятны без догадок.
