# Нормативные ссылки

1. Указывайте полное наименование и обозначение нормативного документа.
2. Проверяйте актуальность используемой редакции перед публикацией.
3. Не ссылайтесь на утратившие силу документы без явного пояснения цели такой ссылки.
4. Для внутренних регламентов указывайте идентификатор и версию, если они предусмотрены системой документооборота.
5. Не копируйте обязательные требования в стайлгайд вместо ссылки, если это создаёт риск расхождения версий.
