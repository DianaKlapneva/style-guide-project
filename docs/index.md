# Стайлгайд корпоративной и технической документации

Этот сайт содержит учебный стайлгайд для корпоративной и технической документации крупной горно-металлургической компании.

Цель стайлгайда — обеспечить понятность, точность, единообразие и управляемость документации в проектах с несколькими авторами и типами документов.

## Область применения

Правила предназначены для:

- внутренних инструкций;
- регламентов;
- руководств пользователя;
- методических материалов;
- информационных материалов;
- документации программных и ИИ-систем.

## Принцип приоритета

Стайлгайд не заменяет обязательные нормативные требования, утверждённые производственные инструкции, требования информационной и промышленной безопасности и корпоративные стандарты.
